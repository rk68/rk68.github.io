corral

My Herdr setup for running a herd of coding agents side by side.

Herdr runs every coding agent in a terminal that stays alive when the window closes, and its UI is built from mods (small JavaScript views you can change or replace). corral is my set of those mods, plus a layout, a theme and some key bindings. Most of it started life in a small Claude pane I keep open on the side.

The mods:

  • Agent Flow: a live view of every agent in a space, in seven views (who delegated what, states, a map, a timeline, context size, lanes and cost). It flags agents that look stuck.
  • PR Stack and PR Diff: my open PRs in merge order, with risk, blockers and one-click fixes, plus a pane to review a diff in.
  • Schedules: agents that run on a cadence, since Herdr has no scheduler of its own.
  • Todos: a todo list that an orchestrator agent works through and hands out to other agents.
  • Usage: Claude Code and Codex plan limits in the sidebar, so I can see when I'm about to hit a wall.
  • Plans: each agent's current plan, pulled from Claude Code and Codex hooks.
  • Contributions: my GitHub contribution calendar in a pixel style, mostly because I wanted it.
  • A Markdown viewer and a file browser, so specs and plans open beside the terminal.
  • Walkthrough: plays a timeline of window commands with captions, which is how I recorded the demo above.

There's a lot more on how I use it day to day in my agentic development setup post. The agent templates pair with the Herdr skills in rstack.
