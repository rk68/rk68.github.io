HyPA-RAG

Adaptive retrieval for AI legal and policy questions, built with Holistic AI.

Language models answer legal and policy questions poorly when their knowledge is out of date or the text mixes qualitative rules with numeric thresholds. Retrieval helps, but a fixed retrieval setup either misses context on hard questions or wastes cost on easy ones.

HyPA-RAG, a hybrid parameter-adaptive retrieval-augmented generation system, adapts to each question. We tested it on New York City Local Law 144, which regulates automated hiring tools.

How it works

  • A fine-tuned DistilBERT classifier rates how complex each question is. The rating sets the number of query rewrites, the number of chunks to retrieve and the knowledge graph limits.
  • Dense and sparse keyword retrieval run together, and a reranker orders the results. A knowledge graph adds facts that plain text chunks miss.
  • An evaluation framework scores answers with set question types and metrics.

Results

On Local Law 144, adaptive retrieval beat every fixed retrieval setting. Selected rows from the paper:

MethodFaithfulnessAnswer relevancyCorrectness
GPT-4o-mini only, no retrieval0.350.630.46

The adaptive rows use the 3-class classifier. With a query rewriter and a reranker added, the full system reached the highest correctness, 0.84. The README has the full table, the repository layout and how to run the code.
