HyPA-RAG

Adaptive retrieval for AI legal and policy questions, built with Holistic AI.

Language models answer legal and policy questions poorly when their knowledge is out of date or the text mixes qualitative rules with numeric thresholds. Retrieval helps, but a fixed retrieval setup either misses context on hard questions or wastes cost on easy ones.

HyPA-RAG, a hybrid parameter-adaptive retrieval-augmented generation system, adapts to each question. We tested it on New York City Local Law 144, which regulates automated hiring tools.

How it works:

  • A complexity classifier (a fine-tuned DistilBERT) rates each question, and that rating picks the number of query rewrites, how many chunks to retrieve and how far to go into the knowledge graph.
  • Hybrid retrieval: dense and BM25 search run together, a reranker orders what comes back, and a knowledge graph fills in the facts that plain chunks miss.
  • An evaluation framework with its own question types and metrics, so we could tell which parts actually helped.

Adaptive retrieval beat every fixed setting we tried on Local Law 144. A few rows from the paper:

MethodFaithfulnessAnswer relevancyCorrectness
GPT-4o-mini only, no retrieval0.350.630.46
Fixed retrieval, top 10 chunks0.850.790.77

The adaptive rows use the 3-class classifier. Adding a query rewriter and a reranker on top got the full system to 0.84 correctness, the best of anything we ran. The README has the full table and how to run the code.

This was all built in 2024, well before I worked the way I do now, so the repo stays as it was for the paper. The live demo on Hugging Face isn't supported any more, but the app code is still in the repo if you're curious.

It was published in the NAACL 2025 Industry Track, and an earlier version was at the EMNLP 2024 CustomNLP4U Workshop.
