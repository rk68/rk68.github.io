rstack

Agent skills, a git safety hook and an installer for Claude Code and Codex.

rstack holds the skills I use in every repo. A skill is a Markdown file that tells a coding agent how to do one kind of task. The agent loads a skill by itself when a task matches the skill's description. One install script links the same skills into Claude Code and Codex, so both agents follow the same steps.

What is in it

  • 28 skills in six groups: write code, design and plan, test and debug, review and ship, run agents in Herdr, and write prose.
  • A git guardrails hook. It blocks commands that lose work or touch production, such as git reset --hard, git push --force and convex deploy. The agent then asks you to run the command yourself.
  • An optional set of global rules for code, tests, stop points and writing style.
  • An installer that links the skills and registers the hook. It is safe to run more than once. To undo it, run the installer with --uninstall.

The hook in use

When the hook blocks a command, the agent sees the reason and stops. This is a real message from an agent session:

BLOCKED by git guardrails: this command discards uncommitted work.
Ask the user to run it, or use a safer command.

Install

git clone https://github.com/rk68/rstack.git && cd rstack
node install.mjs --dry-run   # print what would change
node install.mjs             # link the skills and register the hook
