rstack

The skills, hook and rules I carry into every repo, for Claude Code and Codex.

rstack is where I keep my agent skills. A skill is just a Markdown file that tells the agent how to do one kind of task, and it loads by itself when a task matches its description. One install script links them into both Claude Code and Codex, so every agent works the same way regardless of model.

What's in it:

  • 28 skills for writing code, planning, testing and debugging, reviewing and shipping PRs, running agents in Herdr, and writing prose. Most are adapted from pstack, Matt Pocock's skills and the Convex agent skills, with my own on top.
  • A git guardrails hook that blocks commands that lose work or touch production. The agent sees why it was blocked and asks me to run the command myself.
  • A global rules file (optional), with my list of stop points: the only things an agent has to ask me about.
  • An installer that links it all in, and takes it all out again with --uninstall.

This is what an agent sees when the hook stops it. This one fired while an agent was building this page:

BLOCKED by git guardrails: this command discards uncommitted work.
Ask the user to run it, or use a safer command.

To try it:

git clone https://github.com/rk68/rstack.git && cd rstack
node install.mjs --dry-run   # print what would change
node install.mjs             # link the skills and register the hook
